
Q-Gala is a browser game built for Qiskit Fall Fest at IEM 2026. It teaches basic quantum ideas through play in a shared online space where players walk around as birds. Players sign in with Discord, and the server only lets in members of the event's Discord server who hold one of the required roles. Each player picks a unique name and shapes their bird: its indigo-to-violet colouring and "0/1" chest marks show the odds of the bird reading 0 or 1 when measured. Players then walk a shared plaza where they can use preset phrases and emotes, but there is no free-text chat. From the plaza they can play two games, browse a Hall of Pioneers on the history of quantum computing, and climb a shared leaderboard. 

Gate Dash is a 60-second solo puzzle: turn one qubit state into another using X, H and Z gates, with later levels locking one gate to force three-gate solutions.
Ravens and Robins is a three-player game based on BB84, the first quantum key distribution protocol. Two Robins try to share a secret key while a Raven intercepts notes; wrong guesses scramble notes and leave detectable errors, and random "storms" add noise so that the Robins must decide whether errors come from weather or from a spy. Roles rotate over three rounds, practice bots fill empty seats, and the scoring was tuned by simulation. 

Technically, Q-Gala is a TypeScript monorepo: a Vite and Canvas 2D client, about 19 KB gzipped, hosted on GitHub Pages, and a server running as a Cloudflare Worker that sends everything to a single Durable Object. That one instance holds every WebSocket connection, runs the plaza and the matches, and stores data in its built-in SQLite. The same code also runs on Node 24 for local development and tests. The server decides every outcome and checks every message against rate limits, so clients only say what they want to do. Players receive only the nearby birds they can see, and Ravens and Robins sends each secret only to the role allowed to see it. Logins use OAuth with a one-time ticket and a signed session, allow one live session per player, and revoke the Discord token immediately after the membership check. Secrets live only in Cloudflare. Organisers had admin tools for posting announcements, seeing who was online, and muting or kicking players.
